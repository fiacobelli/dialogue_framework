# Raw Production Exports

This folder is for local-only production exports from the SDOH screening admin page.

Expected files:
- `sdoh-screening-cohort.db`
- `screening_cohort_messages.csv`
- `screening_cohort_visits.csv`
- `screening_cohort_referrals.csv`
- `screening_cohort_patients.csv`
- `private_patient_key.csv`

These files must not be shared publicly or included in paper artifacts.
